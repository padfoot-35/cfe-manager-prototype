# CFE Manager · interactive prototype

Team EasY Peasy (ISB), EY-Parthenon Quest EYP finale.

Live: https://padfoot-35.github.io/cfe-manager-prototype/

An asset-light platform that guarantees and certifies hourly clean energy (CFE90) for Indian data centres. All data is simulated: one month (October 2030) of 15-minute blocks for a 100 MW campus and an 8-factory pool, anchored to the team's platform model v5.

Build: `npm install && npm run build` (output in `docs/`, served by GitHub Pages).
